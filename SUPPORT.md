# Getting help with Zeptap

- **Docs:** https://zeptap.com/docs, including [troubleshooting](https://zeptap.com/docs/reference/troubleshooting).
- **In the app:** Settings › Support sends a report with diagnostics attached. This is the fastest way to get help.
- **Email:** support@zeptap.com, if the app can't be used.
- **Bugs in this repo's code** (configs, plugin, relay): open an issue here.
